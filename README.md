# Wordstat Quiz Canvas App

Это React-приложение CanvasApp с голосовым ассистентом и викториной на основе пары запросов из `wordstat.json`.

Проект содержит:

- одностраничное React-приложение с выбором категории, игровым экраном и отображением счёта;
- интеграцию с `@salutejs/client` для работы с голосовым/текстовым ассистентом;
- компонентную структуру с отдельными страницами и панелями результатов;
- утилиту `scripts/pytrends_parser.py` для обновления данных `src/data/wordstat.json` на основе Google Trends.

## Что делает приложение

Пользователь выбирает категорию, после чего получает пары вариантов из файла `src/data/wordstat.json`.
Каждая пара содержит два ключевых слова, и игрок должен выбрать, какая из двух тем популярнее по трендам.

В приложении реализовано:

- выбор категории из списка;
- рандомизированная очередь вопросов, без повторов до исчерпания набора;
- отображение текущего счёта и его обнуление при возврате в меню;
- визуальная подсказка результата после ответа;
- голосовые команды для выбора категории и ответа.

## Структура проекта

- `src/App.jsx` — главный контроллер приложения, логика игры, состояние, интеграция ассистента;
- `src/pages/TopicSelection.jsx` — экран выбора категории;
- `src/pages/GamePage.jsx` — экран самой викторины с кнопкой «Назад» и счётом;
- `src/components/GameBoard.jsx` — игровая панель с парой вариантов;
- `src/components/ResultPanel.jsx` — итоговая панель после ответа;
- `src/components/CategorySelector.jsx` — визуальный список категорий;
- `src/data/wordstat.json` — набор категорий и пар ключевых слов для викторины;
- `scripts/pytrends_parser.py` — скрипт для обновления значений из Google Trends.

## Быстрый старт

### 1. Настройка окружения

Скопируйте файл `.env.sample` в `.env`:

```powershell
copy .env.sample .env
```

Затем пропишите в `.env`:

- `REACT_APP_TOKEN` — токен вашего SmartApp для доступа ассистента;
- `REACT_APP_SMARTAPP` — имя CanvasApp в SmartApp Studio.

Если нужно отключить автоматическое открытие браузера при старте, добавьте:

```dotenv
BROWSER=none
```

> После изменения `.env` перезапустите приложение.

### 2. Установка зависимостей

Проект проверялся с Node.js `18.x`.

```bash
npm install
```

Или если вы используете Yarn:

```bash
npm install -g yarn
yarn
```

### 3. Запуск

```bash
npm start
```

Или с Yarn:

```bash
yarn start
```
```

Откроется локальная страница с приложением. На экране будут доступны категории и кнопка назад, а также текущий счёт.

## Использование голосового ассистента

Приложение подключено к `@salutejs/client`, поэтому при корректной настройке `REACT_APP_TOKEN` и `REACT_APP_SMARTAPP` можно использовать голосовые команды.

Поддерживаемые команды:

- выбрать категорию: `select_category` / `выбрать категорию`;
- выбрать левый вариант: `select_left` / `левый`;
- выбрать правый вариант: `select_right` / `правый`.

Точная фразеология зависит от настроек SmartApp Code и сценария, загруженного в `scenario-example.zip`.

## Обновление данных из Google Trends

В проекте есть утилита `scripts/pytrends_parser.py`, которая обновляет значения `left_count` и `right_count` в `src/data/wordstat.json`.

Запуск из корня проекта:

```bash
python scripts/pytrends_parser.py --timeframe "all" --sleep 10
```

Где:

- `--source` — путь к исходному JSON (по умолчанию `src/data/wordstat.json`);
- `--output` — путь для записи результата (по умолчанию тот же файл);
- `--geo` — регион Google Trends (по умолчанию `RU`);
- `--timeframe` — период трендов (`all`, `today 12-m`, `today 3-m`, `today 90-d` и т.п.);
- `--sleep` — пауза между запросами, секунды.

Скрипт содержит обработку `TooManyRequestsError`, повторные попытки с backoff и правку совместимости `urllib3`.

## Сценарий SmartApp

В корне проекта лежит архив `scenario-example.zip` с примером SmartApp Code сценария для работы голосового ассистента.

Для полноценной работы нужно:

1. Создать SmartApp Code проект и загрузить в него `scenario-example.zip`;
2. Создать CanvasApp проект в SmartApp Studio;
3. В CanvasApp указать в настройках `SmartApp Code API` URL вебхука из сборки Code проекта;
4. Задать `REACT_APP_TOKEN` и `REACT_APP_SMARTAPP` в `.env`.

## Устранение проблем

### `The term 'yarn' is not recognized`

Если Yarn установлен, но команда не находится в Windows PowerShell, попробуйте запустить `cmd.exe` или используйте `npm` вместо `yarn`.

### `npm install` и конфликт зависимостей с TypeScript

Если появляется ошибка `Conflicting peer dependency: typescript`, можно попробовать:

```bash
npm install --legacy-peer-deps
```

Или установить зависимости через Yarn:

```bash
yarn
```

### Ошибки вебсокета и HTTPS

Если при запуске приложения видны ошибки подключения к `wss://` и не работает голосовой ассистент, откройте соответствующий URL через `https://` и примите предупреждение о сертификате.
